# 用量分析

## 概念介绍

**用量分析** 用于查看 AI 网关的调用统计与请求明细，辅助评估流量、健康与异常。数据依赖实际经网关发生的调用；无调用时图表与列表可能为空。

多租户共用同一上游模型与路由时，可为每位用户发放独立 [API Key](./api-key)（虚拟密钥），在用量分析页按 **API Key**（筛选字段 `api_key_label`）区分流量并查看统计。端到端见 [快速开始/场景2](./quickstart#scenario-metering)（以 **过去7天** 为例）。

控制台路径为 **人工智能 → AI 网关 → 用量分析**。

## 常用操作

### 筛选与查询

页顶筛选条支持：

- **时间范围**：选择近若干小时 / 天或自定义区间后刷新。[快速开始/场景2](./quickstart#scenario-metering) 以 **过去7天** 为例。
- **搜索条件**（**概览** / **分析** 页签）：可按 **API Key**（`api_key_label`）、**model**、**provider**、**source** 等收窄范围。

调整条件后点击刷新；若结果被截断，界面会提示数据不完整，可缩小时间范围或过滤条件后重试。

### 查看概览

切换到 **概览** 页签，常见区块包括：

- **用量分析** 汇总卡片与趋势图：整体请求、Token、成功率等。
- **API Key 用量**：按虚拟密钥汇总请求数、成功 / 失败次数、Token（含输入 / 输出）。多租户计量时以此表对比各密钥用量。
- **AiKey 用量**、**服务健康** 等：按平台能力展示相关汇总（若有数据）。

![](./images/usage-overview.png)

按某一租户查看时，在筛选中选定对应 **API Key** 后再刷新；对比多租户时可不筛 Key，直接阅读 **API Key 用量** 表。

### 查看分析

切换到 **分析** 页签（首次进入会按当前筛选加载），常见区块包括：

- **延迟诊断**：请求数与平均 / 最大 / P50 / P95 等延迟指标。
- **时段热力图**：按时间分布查看请求或 Token 热度（可切换指标）。
- **构成分析**：饼图维度包括 **API Key 构成**、**模型构成**、**Provider 构成**、鉴权来源等；可切换请求数、成功 / 失败、Token 等指标。多租户场景优先关注 **API Key 构成**。
- **模型效率**：按模型查看请求数、每请求 Token 等。

![](./images/usage-analysis.png)

### 查看请求明细

切换到 **请求明细** 页签，按筛选条件查看经网关的调用事件列表，用于排障与核对单次请求（可结合时间范围与 **API Key** 等条件）。

![](./images/usage-events.png)

### 其他说明

用量分析页以查询与展示为主，一般不提供「新建」类资源操作。鉴权、路由与上游配置请分别见 [API Key](./api-key)、[路由规则](./routing)、[供应商](./provider)。

## 常见问题

### 无法按用户 / 租户区分用量

- 确认各用户使用**不同**的虚拟密钥，且均已有经网关的成功调用。
- 在 **概览** 查看 **API Key 用量**，或在 **分析** 查看 **API Key 构成**；筛选栏中的 **API Key** 名称（label）应与创建时一致。
- 更多步骤见 [快速开始/场景2](./quickstart#scenario-metering)。
