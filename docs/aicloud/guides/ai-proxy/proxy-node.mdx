# 接入点

## 概念介绍

接入点表示 AI 网关的对外节点，提供访问地址与心跳状态，可在 [路由规则](./routing) 中选用。客户端实际请求的网关 URL 通常以接入点的 **访问地址** 为准（以控制台展示为准）。

控制台路径为 **人工智能 → AI 网关 → 接入点**。

## 常用操作

### 新建

列表点击 **新建**，填写地址相关字段后提交。

- **名称**：接入点名称。
- **地址**：接入点服务地址（必填）。
- **访问地址**：对外访问 URL（如 `https://gateway.example.com:443`）。
- **心跳超时 (秒)**：判定失活的心跳超时时间，默认常见为 60。

### 查看详情

打开某一接入点的侧栏详情，常见页签包括：

- **详情**：查看地址、访问地址、心跳超时、最后心跳与是否活跃等。
- **操作日志**：排查创建、修改与相关事件。

### 其他操作

- **编辑**：调整地址、访问地址或心跳超时等。
- **启用 / 禁用**：控制是否可被路由选用。
- **删除**：确认无路由引用后再删除。

## 常见问题

### 接入点显示不活跃

检查网关组件与网络连通性，以及 **心跳超时** 是否过短；查看最后心跳时间与操作日志。

### 路由无法选择该接入点

确认接入点已启用，且当前项目权限可见。
