# 供应商

## 概念介绍

供应商表示 AI 网关的上游模型来源，供 [路由规则](./routing) 绑定。常见两类：

- **公有供应商**：在控制台 **新建** 的内置或自定义上游（如 Moonshot、自定义 OpenAI 兼容地址）。
- **推理部署**：在 [推理部署](../llm-inference/deployment) 执行 **注册 AI 网关** 后，由平台自动注册的上游；类型上对应「推理部署」类 Provider。

控制台路径为 **人工智能 → AI 网关 → 供应商**。经 AI 网关使用 Claude（DeepSeek LLM + Moonshot 识图）的端到端步骤见 [快速开始/场景1](./quickstart#scenario-claude)。

## 常用操作

### 新建

列表点击 **新建**。需先完成连接测试，再勾选要导入的模型后提交。

- **供应商类型**
  - **内置供应商**：选择供应商标识（如 Moonshot），按表单填写区域 / API 访问模式 / API URL / API Key 等。
  - **自定义供应商**：自行填写 API 访问模式（OpenAI 兼容 / Anthropic 兼容）、API URL 与 API Key。
- **名称**：供应商条目名称。
- **供应商标识**：内置类型时选择或填写预置标识。
- **API 访问模式**：OpenAI 兼容或 Anthropic 兼容（依供应商能力显示）。
- **API URL / Base URL**：上游接口地址；部分内置供应商由区域自动带出且只读。
- **API Key**：访问上游的密钥（非网关侧的 [API Key](./api-key) 虚拟密钥）。
- **模型**：连接测试成功后，从发现的模型列表中至少选择一个导入；部分列表可能来自内置静态配置而非在线拉取。

推理部署自动注册的供应商一般无需在此手工新建；在部署上 **注册 AI 网关** 即可。

### 查看详情

打开某一供应商的侧栏详情，常见页签包括：

- **详情**：查看类型、地址、启用状态等。
- **模型**：该供应商下已导入的模型。
- **API 密钥**：上游 API 密钥相关信息。
- **操作日志**：排查创建、修改与同步事件。

### 其他操作

- **编辑**：调整配置（受类型与权限约束）。
- **启用 / 禁用**：控制是否可被路由绑定与转发。
- **删除**：确认无路由绑定依赖后再删除。

## 常见问题

### 连接测试后没有可选模型

确认 API URL 与上游 API Key 正确，且节点可访问上游；若提示模型列表来自内置配置，按界面说明勾选即可。

### 列表里出现与部署同名的供应商

多为该 [推理部署](../llm-inference/deployment) 已注册 AI 网关；请在部署侧管理注册状态，避免误删仍在使用的上游。
