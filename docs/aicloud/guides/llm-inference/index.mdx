# AI推理

对应控制台 **人工智能 → 推理**。用于管理 LLM 推理服务：镜像与模型准备、模板规格、部署运行，以及可选的基准测试。引擎类型以模板为准（如 `Ollama`、`vLLM`、`SGLang`）。

## 推荐阅读顺序

1. [快速开始](./quickstart)：导入模型 → 创建部署 → API Key → chat / curl。
2. [推理部署](./deployment)：部署概念、详情页签与运维操作。
3. [推理模板](./template)、[模型文件](./model-library)、[推理镜像](./image)：规格与资源准备。
4. （可选）[基准测试](./benchmark)：对已有部署压测。
5. （可选）[算力卡场景](./gpu-scenarios/)：昇腾、海光等异构算力卡上的推理部署场景。
