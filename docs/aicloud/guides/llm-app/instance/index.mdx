# Agent实例

Agent 实例是按应用类型创建的可运行服务，对应控制台菜单 **人工智能 → Agent → Agent实例**。

平台支持多种 Agent 应用类型；创建前需先在 [Agent模板](../template) 从社区目录 **导入** 对应模板（会同时生成 Agent 镜像与默认模板），再在本页 **新建** 实例。

## 应用类型

| 应用 | 说明 | 文档 |
| --- | --- | --- |
| OpenClaw | 开源自托管的个人智能体助手 | [OpenClaw](./openclaw) |
| HermesAgent | Nous Research 开源自主 Agent | [HermesAgent](./hermes) |
| Dify | LLM 应用开发与工作流编排平台 | [Dify](./dify) |
| ComfyUI | 图像生成与节点式工作流应用（通常需 GPU） | [ComfyUI](./comfyui) |

各应用页的「快速开始」均按 **导入模板 → 创建实例 → 后续配置** 组织。通用字段与运维说明见 [Agent模板](../template)、[Agent镜像](../agent-image)。
