# 应用

对应私有云控制台顶层菜单 **应用**。当前分组为 **桌面**，菜单顺序为 **桌面实例** / **桌面模板** / **桌面镜像**。主路径为：在 **桌面模板** **导入** 社区桌面应用 → 在 **桌面实例** **新建** 实例 → 在详情 **登录信息** 中点击 **登录地址** 打开桌面。端到端步骤见 [快速开始](./quickstart)。

桌面实例运行在 [容器主机](../container/) 之上，适合有状态的云桌面类工作负载。类型均为 Desktop（`desktop`）。

## 推荐阅读顺序

1. [快速开始](./quickstart)：导入模板 → 创建实例 → 访问桌面。
2. [桌面实例](./instance)：创建、访问与运维操作。
3. [桌面模板](./template)、[桌面镜像](./image)：导入、规格与运行时镜像。

## 菜单对照

| 控制台菜单 | 说明 |
| --- | --- |
| 桌面实例 | 基于桌面模板创建并管理桌面应用实例 |
| 桌面模板 | 从社区目录 **导入**（主入口），或 **新建** 自定义规格 |
| 桌面镜像 | 桌面类应用的容器镜像（含 **应用标识**） |
